# 踩过的坑

起初是空的，这很正常。**规则：任何花超过 20 分钟才解决的问题，解决完立刻记在这里。**

价值在于：同一个坑，第二次遇到时是 2 分钟而不是 20 分钟——不管是你还是 agent 遇到。

## 格式

```markdown
### 一句话描述症状（用你当时看到的现象，不是事后总结的原因）

**现象**：报错原文、或者具体哪里不对。报错原文要原样贴，这是搜索时最有效的关键词。
**原因**：真正的原因。
**解决**：具体怎么做。
**为什么会踩到**：如果原因和症状离得很远，写一句，帮下次更快定位。
```

症状要用**当时看到的样子**写。事后你知道"是因为环境变量没加载"，但下次遇到时你看到的是一串莫名其妙的报错——用后者当标题才搜得到。
