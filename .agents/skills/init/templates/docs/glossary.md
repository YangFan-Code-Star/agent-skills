# 术语表

统一叫法，避免同一个概念在代码、文档、对话里有三种名字。

`AGENTS.md` 里只放最核心的几个，其余在这里展开。

## 怎么写一条术语

每条要回答三件事：**是什么、边界在哪、代码里叫什么**。

边界是最容易出错也最有价值的部分。"月支出"这个词，含不含一次性的大额消费？含不含还房贷的本金部分？不同的选择会得出完全不同的结论，而代码里只能看到一个 `monthlyExpense` 变量，看不出你选了哪个口径。

```markdown
### 术语名

一句话定义。

**边界**：明确包含什么、排除什么、为什么这样划。
**代码中**：`variableName`，位于 `path/to/file`。
**注意**：容易和 ⟨另一个近似概念⟩ 混淆，区别在于 ⟨……⟩。
```
