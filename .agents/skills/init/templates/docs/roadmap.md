## 明确不做

TODO(init): 逐条列出确定不做的事。

**这一节不能是空的。** 它挡掉的是 agent 自作主张的扩张——那些"听起来很自然、顺手就加上"的功能，每一个都会带来长期维护成本。写下来，agent 就会在提议前先否决自己。

如果一时想不出，问自己：有没有什么功能，别人看到这个项目会觉得"顺便也做了吧"，而你确定不要？
