# 任务日志

一个 append-only 的队列：任务结束时把值得记住的东西追加到「待合并」下面，`/maintain` 定期把稳定内容合并进 [docs/plan.md](plan.md) 或 `AGENTS.md`，然后删掉已合并条目。

## 什么时候写

- 做了一个有取舍的决定
- 踩了一个超过 20 分钟才解决的坑
- 用户纠正了一个理解
- 同一个流程或概念被解释了两次以上

**模型本来就知道的不要写**（"要写测试"、"注意错误处理"）。日志也要花钱合并。

## 条目格式

```markdown
### YYYY-MM-DD 类型 — 一句话

- **现象**：当时发生了什么。
- **该记住**：下次要遵守 / 知道的那句话。
- **去向**：docs/plan.md / AGENTS.md 铁律 / 留观
```
